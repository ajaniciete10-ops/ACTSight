11. ACTS AGENT CONSOLE
======================

ACTS Agent Console is a task-executing conversational interface designed primarily for teachers.

It should NOT be described as merely a chatbot that produces plain text.

The intended concept is:

Teacher gives a natural-language instruction
→ system interprets the instruction
→ system converts it into structured parameters
→ system executes an approved task
→ system returns the result

Possible supported tasks include:

* quiz generation
* quiz dissemination
* class performance queries
* other approved teacher tasks

The teacher should not be required to manually construct technical AI prompts for supported tasks.

For quiz generation:

* the teacher may provide learning resources such as PDF or PowerPoint files
* the system may generate quiz content based on those resources
* models such as T5 may be used where officially approved
* generated content should follow the approved assessment requirements

For quiz dissemination:

* teacher Gmail may be used
* quizzes may be distributed through unique links
* links may be time-limited or expiring where approved

Do not claim a specific implementation unless confirmed by the latest technical documentation.

ACTSight is not an ACTS Computer College-exclusive capstone system.

The goal is to help the research group produce accurate, consistent, understandable, academically appropriate, and defensible thesis documentation while preserving the project's intended adaptability for other educational institutions.
