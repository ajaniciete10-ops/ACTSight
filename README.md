# ACTSight

**ACTSight: An OCR-Based Automated Assessment and Agentic Console for Quiz Automation, AI-Assisted Learning Plan Generation, and Student Retention Analytics**

ACTSight is a thesis project focused on **OCR-based quiz automation, AI-assisted learning plan generation, and student retention analytics**.

ACTS Computer College serves as the **research setting and institutional context** of the study. ACTSight is designed as a **system blueprint** that may be adapted by other educational institutions according to their own requirements.

## Repository Structure

* `01_THESIS/` — Thesis documents
* `02_RESEARCH/` — Research materials and references
* `03_SYSTEM/` — System documentation
* `04_MEETINGS/` — Meetings and consultation records
* `05_TEMPLATES/` — Project templates
* `06_AI_CONTEXT/` — AI instructions, project context, and terminology
* `07_PROMPTS/` — AI prompts

## Project Documentation

For AI-assisted work, consult the relevant documents in `06_AI_CONTEXT/` and `07_PROMPTS/` before working on thesis or system tasks.

The **latest approved project documents and decisions are the source of truth**. Older or superseded documents should not be treated as current project requirements.
