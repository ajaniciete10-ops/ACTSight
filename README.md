# AGORA
### Agent Generator and OCR-based Recognition Assistant for Quiz Automation, AI-Assisted Learning Plan Generation, and Student Retention Analytics

## Project Overview

**AGORA** is a proposed educational assessment and analytics system designed to support teachers in automating quiz assessment, generating AI-assisted learning plans, and analyzing student retention-related indicators.

The system combines Optical Character Recognition (OCR), AI-assisted processing, and educational data analysis to help reduce manual assessment work and support data-informed instructional decisions.

This repository contains the research documentation, AI context files, writing guidelines, and supporting materials used in the development of the AGORA thesis.

## Research Objectives

AGORA aims to:

- Automate the recognition and assessment of quiz responses from paper-based and digital assessments.
- Support the generation of AI-assisted learning plans based on assessment results and learning needs.
- Analyze student retention-related indicators using attendance and assessment data.
- Provide teachers with tools for assessment review, learning support, and academic monitoring.

## Core System Components

### 1. Quiz Automation and OCR-Based Recognition
Processes paper-based answer sheets and supports digital quizzes. OCR-based recognition and assessment workflows are intended to reduce manual encoding and grading.

### 2. AI-Assisted Learning Plan Generation
Supports the generation of learning plans using assessment results, identified learning needs, and relevant educational objectives.

### 3. Student Retention Analytics
Uses attendance records and assessment-related data to help identify patterns associated with student retention.

### 4. Agent Console and Learning Support
Provides a teacher-facing workspace for interacting with AI-assisted system functions and supporting learning-related tasks.

### 5. Assessment Review and Data Management
Supports the review and correction of uncertain recognition or assessment results to help maintain data accuracy.
